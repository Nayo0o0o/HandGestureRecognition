
# HandGestureRecognition

A real-time hand gesture recognition system based on computer vision and machine learning.

## Project Overview

This project aims to recognize hand gestures through webcam images and explore machine learning methods for human-computer interaction.

## Technology Stack

- Python 3.12
- OpenCV
- MediaPipe
- NumPy
- Scikit-learn
- Matplotlib

## Development Plan

- [ ] Hand detection
- [ ] Hand landmark extraction
- [ ] Feature engineering
- [ ] Gesture classification
- [ ] Model evaluation
- [ ] Human-computer interaction
